TLB TOUR FINAL PROJECT
======================

This bundle contains two separate Android projects:
1) TLB-TOUR-PLAYER  -> Player App
2) TLB-TOUR-ADMIN   -> Admin App

Brand:
- App name: TLB TOUR
- TLB TOUR logo included
- Dark blue / neon esports style

Reference APK:
The uploaded reference APK was inspected for feature/screen terminology. The implementation here is a new Android project, not a copied proprietary APK/code.

Player features included:
- Username + 6-digit password login
- Registration + referral code
- Home dashboard
- Live/upcoming tournaments
- Join tournament with wallet deduction
- My Matches + room details when available
- Results
- Auto Point Table
- Wallet
- Deposit / Withdraw
- Referral system
- Daily earnings leaderboard
- Notifications
- Profile
- Firebase Authentication / Firestore / Storage
- Admin access check
- Match-result screenshot OCR using ML Kit

Admin features included:
- Admin login/access control
- Create/manage tournaments
- Match result + screenshot OCR
- Deposit/withdraw request management
- User management
- Earnings leaderboard
- Notifications

IMPORTANT:
Each app is a standalone Gradle Android project. Build them separately from their respective folders.
Do not upload the ZIP itself into the Android Studio project as source; extract it first.
