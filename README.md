# TLB TOUR — Final Project

Free Fire tournament Android app.

Included:
- Username login + exactly 6-digit password
- Unique username registration
- Tournament details, join protection, player limits and wallet deduction
- Match found/live room ID and password
- Wallet, deposit, withdraw and transaction history
- Referral code and direct referral count
- Results, auto point table and daily earnings leaderboard
- User/broadcast notifications
- Profile
- Admin tournament creation and match control
- Admin transaction approval
- Admin user/leaderboard/notification tools
- Screenshot OCR result entry
- Firebase Authentication, Firestore, Storage and ML Kit
- GitHub Actions APK build
